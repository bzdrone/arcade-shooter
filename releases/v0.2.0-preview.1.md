# Arcade Shooter v0.2.0-preview.1

The editable MakeCode Arcade soldier game, now with game modes and **Mod** blocks for writing your own game mode rules. The Mod blocks use the same names as Battlefield 6 Portal's scripting, so the ideas carry over.

## Start here

1. Download **arcade-shooter.png** from this release's assets. Use the original file, not a screenshot or converted image.
2. Open https://arcade.makecode.com/ and drag the PNG onto the page, or choose **Import → Import File**.
3. Press Play if needed. Use the arrow keys to move and **Space / A** to shoot along your last movement direction.

No installation, Git checkout, or source assembly is required. GitHub's automatic "Source code" archives are for authors; learners should download the PNG instead.

## What's new since v0.1.0-preview.1

- **Game modes:** choose **deathmatch**, **gun game** or **no mode** with the **set shooter mode** block. Deathmatch plays as before.
- **Gun game:** everyone starts with a pistol; each elimination moves only that player up to SMG, shotgun, then knife. The first knife elimination wins for that player's team.
- **Mod blocks:** events (game started, player deployed, player died, player earned a kill), scores and winning, teams, per-player and game variables, messages with `{}` blanks, and waiting. **Weapons** blocks give and check weapons. Both built-in modes are written with these blocks and can be read as examples.
- **New activity:** `02-mod-rules.md`, writing a scoring rule and a kill streak in no mode.
- On-screen notifications and announcements that do not pause the game.

## Included

- **arcade-shooter.png**: the game with embedded editable source, custom Blocks, and tilemap assets.
- **INTRO.md**: import instructions, controls, game modes and a first experiment.
- **01-weapon-tuning.md**: the predict → change → test → explain weapon activity.
- **02-mod-rules.md**: the game mode rules activity.
- **LICENSE**: MIT license.

The handouts are separate downloads, not embedded in the game PNG.

## Preview status

- Arcade compilation and 46 host-side rule, mode, Mod and navigation tests passed.
- Real-simulator checks covered combat, cover routing, respawns, both deathmatch endings, full gun game ladders and wins for both teams with button restart, messages, weapon range, and a learner-style program built only from Mod blocks, converted to Blocks and back with no grey blocks.
- The exact PNG passed fresh local and hosted editor import, custom Blocks checks and tilemap-editor opening. On the public Arcade site, gun game was selected in Blocks and a real elimination advanced the weapon.
- Ending and ladder checks used controlled placements and seeded scores; they were not complete natural matches.

**Not yet established:** learner evaluation of either activity, and gun game balance. The human soldier is much faster than the bots, which matters more in gun game. Bot behavior is intentionally simple.

After editing settings, **stop and start** the simulator to recompile. Fast restart can reuse old code. Keep the original PNG to return to the baseline.
