# Arcade Shooter v0.2.0-preview.2

A gentler start: the editable game now opens directly in **Blocks**, with help on the custom blocks and a simpler first activity.

## Start here

There are only two downloads you need:

1. **INTRO.md** — open this first. New to MakeCode Arcade? It suggests beginner tutorials and a practice save/import before trying the shooter.
2. **arcade-shooter.png** — the editable game. At https://arcade.makecode.com/, choose **Import → Import File** and open the original downloaded PNG. It opens in Blocks.

Use the arrow keys to move and hold **Space / A** to shoot. The introduction guides you through changing just one number to make hits stronger.

You do not need Git, a local toolchain, or the automatic **Source code** archives GitHub adds below. The PNG contains the editable project, not just a picture; keep the original file rather than a screenshot or converted image.

## What's changed

- **Blocks-first opening:** no switch from JavaScript required after import.
- **A smaller first session:** get comfortable with Arcade, play briefly, then change damage from 1 to 3. No need to finish a match or choose a different game mode.
- **Save/import practice:** use a finished tutorial project to learn how an editable game is saved inside a PNG and opened again.
- **Block help:** hover over custom blocks to read descriptions. Mod help is adapted from Portal SDK 2.1.2.0, with Arcade-specific differences explained; Shooter and Weapons help describes this game's settings and presets.
- **Fewer downloads:** optional [weapon experiments](https://github.com/bzdrone/arcade-shooter/blob/main/lessons/01-weapon-tuning.md) and [later scripting activity](https://github.com/bzdrone/arcade-shooter/blob/main/lessons/02-mod-rules.md) can be read online. Checksums and build records are retained by the author rather than attached as learner downloads.

The game modes and gameplay rules are unchanged from the previous preview. The [MIT license](https://github.com/bzdrone/arcade-shooter/blob/main/LICENSE) remains in the repository. Instructions are separate from the game PNG.

## Preview checks and limits

- Arcade compilation and host-side gameplay/pathing tests passed.
- The exact PNG was imported into clean local and hosted Arcade sessions and opened directly in Blocks.
- Local browser checks covered basic movement, held/released shooting, retained aim, a wall boundary, and changing damage in Blocks with the new value taking effect after stop/start.
- Local and hosted checks verified custom blocks without grey JavaScript, help text on all 32 custom blocks, simulator startup, and tilemap-editor opening.
- Hosted validation used Arcade 4.1.28 / PXT 13.1.25.

These are automated checks, not a full natural-match playtest or a beginner trial. Neither learning activity has been evaluated with a learner, and gun-game balance remains unverified. After changing settings, stop the game preview and press Play rather than using fast restart.
